# Reproducible Simulation Benchmark (Section 10)

Executed on the **Orion** compute server (2x Xeon 6787P, 344 cores, 1007 GB) on
2026-08-05, 300 workers, wall time ~11 min. Ecological parameters are the locked
strong-Allee slice (source_pack/04). All numbers in the manuscript's Section 10 and
in `artifacts/manifests/manifest.json` are generated by this code — none typed by hand.

## Code (`benchmark/*.py`)
- `core.py`  — exact strong-Allee algebra (equilibrium, Jacobian, T(A), D(A), alpha*(A)),
  Caputo PECE solver (fractional Adams-Bashforth-Moulton), Mittag-Leffler reference,
  linear transfer functions.
- `designs.py` — input waveforms (pulse, multiscale pulse train, sinusoid, robust
  multisine, chirp, PRBS), observation channels, sampling, SNR, factorial grid.
- `bench.py` — linear + nonlinear simulators for the 4 memory mechanisms (ODE, Caputo,
  DDE, latent), equal-energy inputs, divergence/safety guard, discrimination primitives.
- `run_all.py` — driver: gates -> solver validation -> full-factorial linear-Gaussian
  discrimination -> nonlinear Monte-Carlo confirmation (parallel) -> manifest. JSONL resume.
- `smoke_test.py` — fast correctness check exercising every path.

Reproduce: `~/venv/bin/python run_all.py --workers 300 --reps 200 --N 400`

## Results (`benchmark/results/`)
- `gates.json` — analytic gates (x*=2/3, alpha*(0.30)=0.9690122761517083 to 12 digits,
  full ctrb/obsv ranks). PASS.
- `solver_validation.json` — PECE vs Mittag-Leffler, max abs err 2.5e-4, converges. PASS.
- `linear_factorial.json` — 1458-cell exact linear-Gaussian discrimination; design
  ranking by mean min-pairwise KL: prbs > pulse > multiscale > multisine > sinusoid > chirp.
- `nonlinear_confusion.json` — 945 cells x 200 replicates. Overall model-selection
  accuracy 0.749 +/- 0.011 (chance 0.25). Best design: **multiscale** (0.846). Per-class:
  ODE 0.967, Caputo 0.718, DDE 0.788, latent3 0.881, latent1 0.451. Zero divergence.
- `manifest_orion.json`, `state_nl.jsonl`, `run2.log` — run manifest, per-cell state, log.

## Headline findings
1. Broadband / multiscale / pulse excitation discriminates memory mechanisms far better
   than narrowband sinusoid or chirp (both linear-exact and nonlinear agree).
2. Multiscale excitation is the best nonlinear design (accuracy 0.846).
3. Caputo<->ODE confusion concentrates as alpha->1; single-mode latent is the hardest to
   distinguish (mimicry / no-free-lunch, source_pack/07 T10) -- a genuine limitation, honestly reported.
