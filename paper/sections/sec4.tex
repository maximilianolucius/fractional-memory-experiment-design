\section{Numerical Methods and Validation}
\label{sec:numerics}

The computational layer is designed to support the analytical claims rather than replace them. All scripts and machine-readable outputs are released in the accompanying benchmark and figure directories.

\subsection{Solvers}
ODE and latent-state systems are integrated with fourth-order Runge--Kutta. Retarded DDEs use an interpolated-history RK4 solver. Caputo systems use the fractional Adams--Bashforth--Moulton PECE scheme~\cite{F02}; its scalar implementation is validated against the exact Mittag--Leffler solution.

For the combined fractional-delay model~\eqref{eq:fdmodel}, we use the same PECE history convolution while evaluating the delayed prey term by interpolation of the already computed trajectory. For $\tau>0$ all reported grids satisfy $\tau\ge h$, so the delayed value required by the corrector lies in known history. The two limiting cases provide strong numerical gates:
\begin{itemize}
    \item $\tau=0$ is delegated exactly to the validated Caputo solver;
    \item at $\alpha=1$, the fractional-delay solver converges to the independent DDE RK4 solution.
\end{itemize}
At $A=0.25$, $\tau=0.35$, the maximum absolute discrepancy between the $\alpha=1$ fractional-delay solver and the DDE solver is $6.75\times10^{-6}$ at $N=200$, $1.68\times10^{-6}$ at $N=400$, and $4.20\times10^{-7}$ at $N=800$. For the representative fractional-delay cell $(\alpha,\tau)=(0.85,0.35)$, the max difference against the $N=800$ solution drops from $2.18\times10^{-3}$ at $N=200$ to $8.05\times10^{-4}$ at $N=400$.

\subsection{Inputs, observations, and metrics}
Six bounded inputs are compared at the common peak-amplitude budget $\|u\|_\infty\le0.10$: pulse, multiscale pulse train, sinusoid, multisine, chirp, and pseudorandom binary sequence (PRBS). Observations use prey, predator, or both channels. Numerical safety is reported separately from solver non-divergence using the minimum Allee margin
\[
\min_t(x(t)-A)
\]
and the rate of threshold crossing.

For fractional-delay experiments we additionally report (i) trajectory distance to the pure Caputo limit, (ii) trajectory distance to the pure DDE limit, (iii) predator peak time and amplitude, and (iv) a robust bridge-discrimination score defined as the minimum of the distances to the two limiting explanations.


\subsection{Validation matrix and numerical resolution}
The main numerical claims are associated with explicit validation gates rather than a single solver run. Table~\ref{tab:solver-validation} collects the convergence checks used in the released package. The scalar Caputo PECE implementation is compared with an exact Mittag--Leffler solution. The combined fractional-delay implementation is checked independently at the integer-order boundary against the DDE RK4 solver, and an interior fractional-delay cell is subjected to self-convergence. The error decreases monotonically in every reported sequence.

The validation strategy is deliberately heterogeneous. An agreement between two implementations that share the same discretization can hide a common coding error; therefore the most important boundaries are checked against a mathematically different reference. At $\tau=0$, the fractional-delay code delegates to the already validated Caputo implementation rather than duplicating the same calculation. At $\alpha=1$, by contrast, the memory convolution collapses to an integer-order problem and the output is compared with the separate interpolated-history DDE RK4 path. The two checks test opposite boundaries of the combined model.

\subsection{Experimental grid and reproducibility}
The benchmark is organized around a small number of interpretable axes rather than unconstrained parameter search. The common peak actuator budget is $\|u\|_\infty\le0.10$. The original four-class stable benchmark varies Allee level, fractional order, SNR, observation channel, and waveform family; each cell is replicated 200 times. The dedicated fractional-delay campaign is smaller and targeted: it uses $A=0.25$, $\alpha\in\{0.75,0.85,0.95\}$, $\tau\in\{0.15,0.30,0.45\}$ for the design comparison, and a denser $(\alpha,\tau)$ grid for the bridge plots. Table~\ref{tab:experiment-grid} summarizes the main numerical axes.

All quantities used in the figures are generated from machine-readable JSON or NPZ outputs. The fractional-delay script writes the solver validation sequence, the design ranking, and the bridge arrays together with the four figures. This separation between simulation generation and paper rendering is useful for audit: plots can be regenerated without rerunning the large four-class benchmark, while the archived benchmark statistics can be checked independently.
