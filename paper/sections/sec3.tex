\section{Dimensionally Consistent Controlled Memory Models}
\label{sec:models}

To ensure dimensional consistency when introducing a fractional derivative of order \(\alpha\), we introduce a reference time scale \(\tau_0\).
The dimensionally consistent commensurate Caputo model for the controlled strong-Allee predator-prey system is

\begin{equation}
\tau_0^{\alpha-1} {}_{0}^{C}D_{t}^{\alpha} z(t) = f(z(t);\theta) + B u(t),
\label{eq:dimcons}
\end{equation}

where \(z=(x,y)^\top\) is the state vector (prey, predator), \(f\) is the ecological vector field, \(B\) is the input matrix, and \(u(t)\) is the control input.
At \(\alpha=1\), equation~\eqref{eq:dimcons} reduces exactly to the integer-order ODE.

The ecological vector field \(f\) is that of the strong-Allee predator-prey model:
\begin{align}
f_1(x,y) &= r x \left(1-\frac{x}{K}\right) \left(\frac{x}{A}-1\right) - \frac{a x y}{1 + h x},\\
f_2(x,y) &= e \frac{a x y}{1 + h x} - m y,
\end{align}
with the locked parameter values \(r=3/2\), \(K=1\), \(a=1\), \(h=1/2\), \(e=4/5\), \(m=2/5\) inherited from the validated baseline.

We consider four candidate dynamic-memory mechanisms around a common experimental operating point. The ODE and Caputo mechanisms share the ecological Jacobian $J(A)$ exactly; the retarded-DDE and finite-state latent alternatives are calibrated rival response laws with the same input/observation channels and physical units, but their internal generators $A_0,A_1$ and $\bar A$ are not literally the same Jacobian:
\begin{enumerate}
    \item \textbf{M\_ODE}: integer-order ODE with dynamics \(\dot{\xi} = J \xi + B u\) (memory horizon: none).
    \item \textbf{M\_Caputo}: fractional derivative of order \(\alpha \in (0,1)\) with dynamics \(\tau_0^{\alpha-1} {}_{0}^{C}D_{t}^{\alpha} \xi = J \xi + B u\); the order \(\alpha\) belongs to this mechanism alone.
    \item \textbf{M\_DDE}: retarded delay differential equation with finite state dimension and a single discrete delay \(\tau\), \(\dot{\xi} = A_0 \xi(t) + A_1 \xi(t-\tau) + B u\).
    \item \textbf{M\_latent,m}: finite-dimensional linear time-invariant latent state model of dimension \(m\) with dynamics \(\dot{q} = \bar{A} q + \bar{B} u\), \(y = \bar{C} q\).
\end{enumerate}
Only \textbf{M\_Caputo} carries a fractional order; the ODE, DDE, and latent mechanisms are integer-order. They are compared through matched input and observation channels and a common observation-noise model. The fractional transfer is \(G_\alpha(s)=C(q_\alpha(s)I-J)^{-1}B\), whereas the DDE and latent classes use their own declared generators. Figure~\ref{fig:model-family} summarizes this distinction.

The dimensional consistency enforced by $\tau_0$~\cite{F02,F03,F04} ensures that the fractional order $\alpha$ does not spuriously alter the units of the ecological rates, allowing a fair comparison between the memory hypotheses.
